# DocMind · 带原文依据的论文问答工作台

读一篇新论文时，你可能想先了解方法，再找到某个实验的设置，最后判断一个结论究竟适用于什么条件。DocMind 帮你围绕这些问题定位论文内容，并把回答与原文放在一起核对。

**上传论文 → 选择阅读范围 → 提问 → 查看引用 → 回到 PDF 验证。**

适合研究生、科研人员和需要阅读技术论文的开发者。当前提供本地源码试用版，优先面向可选中文字的 PDF。

[下载试用包](https://github.com/xinyu68563/Docmind/raw/refs/heads/main/downloads/docmind-0.1.0-local-source.zip) · [安装与启动](docs/TRYOUT.md) · [提交使用反馈](https://github.com/xinyu68563/Docmind/issues)

## 从你的阅读任务开始

| 你正在做什么 | 可以怎样提问 | 核对时关注什么 |
| --- | --- | --- |
| 初次阅读，建立理解 | “这篇论文解决什么问题？方法分为哪些步骤？请引用原文。” | 问题定义、方法步骤是否对应正文，而不只是摘要 |
| 深入研究方法 | “这个收敛结论依赖哪些假设？作者在哪里讨论这些条件？” | 定理前提、适用范围，以及回答是否遗漏限制 |
| 准备复现实验 | “实验用了什么数据、硬件和训练设置？没有报告的项目请明确标注。” | 数据集、单位、实验设置和表格是否一致；论文未报告的信息不应被补出来 |
| 对照阅读多篇论文 | “这两篇论文对同一问题分别采用什么方法？请分别给出依据。” | 两篇都已选中，引用没有混用；不同数据集或指标不能直接比大小 |
| 整理组会或审稿问题 | “作者给出的实验证据能支持哪些结论？有哪些需要进一步核实的表述？” | 区分论文原文、模型的归纳和你的判断，再决定是否写入笔记 |

建议从一篇论文、一个具体问题开始。需要对比时再加入相关论文，每次最多选择 10 篇。跨论文的归纳仍需逐篇核对，DocMind 不会替你完成完整的系统综述。

## 第一次使用：完成一次可核对的阅读

### 1. 打开工作台并确认运行模式

先按[安装指南](docs/TRYOUT.md)准备环境。启动后，浏览器打开本机工作台。

- **真实模型模式**：用于阅读自己的论文，需要兼容的 NVIDIA 显卡和单独下载的模型。已在 RTX 5060 8GB 上验证；其他配置需要实测。
- **演示模式**：用于了解上传、任务进度和原文查看流程，无需 GPU 或模型下载。界面显示“桩后端 · 非模型”，回答是固定模拟内容，不能用它评价论文问答效果。

首次安装需要联网获取依赖和模型；准备完成后，真实模式的论文处理和推理在本机进行。

### 2. 上传论文，等待“可提问”

在文档库上传 PDF，等待解析和索引完成。若导入失败，先查看提示；扫描件需要先进行 OCR，再上传能选中文字的版本。

当前单份 PDF 上限为 **20MB、200页、1200个切分片段**。超出限制会提示失败，不会按完整论文继续回答。

### 3. 选择论文，再提出具体问题

选择状态为“可提问”的论文，确认提问框上方显示的范围就是本次要阅读的材料。新安装没有预置论文，必须先上传并选择。

例如，阅读 *Attention Is All You Need* 时，可以问：

> 论文中的编码器有多少层？模型维度和注意力头数分别是多少？请引用对应原文。

一次提出相互关联的少量问题，比“全面分析这篇论文”更容易核对。提问时可说明你需要定义、条件、实验数字还是方法比较，并要求未报告的信息明确标注。

### 4. 阅读回答，同时打开引用

点击回答中的引用编号或下方证据片段，查看完整片段；切换到“原 PDF”，核对对应物理页。可以翻页、缩放，也可以打开完整 PDF。

核对三件事：**是否来自正确论文、原文是否支持这句话、数字和条件是否完整**。PDF 物理页可能与论文印刷页不同。长片段跨页时，需要继续翻阅相邻页。

### 5. 确认后再整理笔记

你可以回看任务历史或导出任务记录，保留问题、回答和证据，方便继续核对。写入组会材料、论文或实验计划前，请以原论文为依据，直接引用论文的正式书目信息。

## 怎样理解回答状态

| 工作台显示 | 对阅读有什么含义 | 建议操作 |
| --- | --- | --- |
| 模型自校验通过 | 模型认为自己的回答与提供的证据一致 | 重要结论仍打开原文核对 |
| 回答未通过校验 | 校验发现问题，回答仍供你查看 | 检查提示和引用；自检本身也可能误判 |
| 无法确认 / 未校验 | 系统没有形成可靠的校验结论 | 暂不采信，直接检查 PDF |
| 无引用 / 论文未报告 | 缺少可定位依据，或回答认为论文没有提供信息 | 查看相关章节，必要时把问题缩小；不要补造数字 |

这些状态帮助你安排核对顺序，不能代替原文验证。模型可能错答、漏引或前后矛盾；证据片段也可能没有包含全部前提。

## 哪些任务需要另行处理

- 扫描件、只存在于图片中的表格或公式，可能无法被完整检索；当前尚未接入 OCR 和图像理解。
- 公式密集、复杂表格和跨页推导需要重点查看 PDF 页图；文本抽取可能丢失布局或符号。
- 正在生成时，取消操作需等待当前模型调用结束后才能生效。首次回答还需加载模型，等待可能较长。
- 当前面向个人本地阅读。提供阶段进度、引用片段和 PDF 翻页；尚未提供页内框选高亮、账号或多用户在线服务。

## 反馈一个阅读问题

请在[Issues](https://github.com/xinyu68563/Docmind/issues)中说明：你想完成的阅读任务、运行模式、操作步骤、问题、回答与对应引用页，以及你在原文中发现的不一致。安装问题另附系统、Python版本和显卡信息。

只公开你有权分享的材料。涉及未公开论文时，可以描述问题并提供最小复现，避免上传原稿或完整日志。
