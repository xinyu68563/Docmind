# 使用指南

完成[安装](TRYOUT.md)后打开工作台。真实问答默认地址为 http://127.0.0.1:8089，演示模式按快速开始使用8088。

## 上传与选择

在左侧文档库上传PDF。状态会依次显示解析、索引和“可提问”；失败时查看提示后重试。选择就绪论文后，提问框上方显示本次阅读范围，最多选择10篇。新安装没有预置论文，先上传并选中后再提问。

## 提问

输入具体问题，点击“检索并回答”；也可使用Ctrl+Enter。方法步骤、定义、实验条件或明确的数字比较更便于核对。多篇问题需先选中相应论文。回答设置可调整输出预算和最多反思轮数，默认设置适合先开始试用。首次问题需加载模型，等待可能较长。

## 查看依据

点击回答中的引用编号或下方证据片段，右侧显示完整原文。切换“原PDF”查看物理页，使用翻页和缩放核对，或打开完整PDF。物理页可能与论文印刷页不同。跨页片段需继续查看相邻页。

核对来源论文、数字单位、适用条件和引用是否支持该句。模型自校验通过只表示模型的判断；失败也可能是自检误判。无法确认、未校验或无引用的内容需要直接查看原文。论文未报告的信息不应通过其他指标推算后冒充原文。

## 历史与导出

在历史任务中回看问题与结果，可导出任务记录作为核对材料。回答完成后仍能查看来源。运行中的取消会在当前模型调用结束后生效；排队任务可取消而不执行。

## 演示模式

“桩后端 · 非模型”及答案中的STUB标识表示演示输出。它用于体验上传、任务和PDF查看，回答内容与论文无关。演示与真实模式的文档索引分开保存。

## 遇到问题

导入失败先确认PDF能选中文字且不超出限制。安装/启动故障见[安装说明](TRYOUT.md#常见问题)。回答问题请保留提问、原答案及引用页，通过[Issues](https://github.com/xinyu68563/Docmind/issues)反馈可公开的材料。
