# 简历与面试说明

**DocMind：支持证据溯源的本地论文问答系统**

Python / PyMuPDF / BM25 / bge-m3 / NumPy / Qwen2.5-7B NF4 / Spring Boot / Vue 3。

- 实现PDF结构化解析与切分，融合BM25关键词和bge-m3向量召回，通过RRF合并排序；支持上传论文独立建索引及最多10篇文档的限定范围检索。
- 实现规划、检索、反思、回答与校验的Agent流程，设置轮次和生成token预算，逐调用记录输入输出、耗时与终止原因。
- 以Spring Boot桥接常驻Python worker，实现有界队列、任务状态及取消、阶段SSE与持久化；前端提供引用片段和PDF物理页溯源。
- 建立控制流、接口和数据完整性回归，冻结问题与原始产物，通过原文核对定位引用错配、措辞矛盾和模型自检误判。

职责、时间、团队规模应按本人实际参与填写，并说明使用AI辅助开发。没有训练模型，没有全量准确率结论。不要把原计划中的LangGraph、pgvector、Redis、云API、计费或多租户写成已实现。

面试前能解释：结构切分与普通切分区别；RRF为何保留两路排名；NumPy暴力检索适用规模；8GB上CPU embedding和GPU Qwen的内存取舍；排队取消和运行取消区别；模型自检为什么不能证明事实正确。建议演示上传→指定范围→带引用答案→原文→任务记录，并主动展示一次未通过校验的回答。
